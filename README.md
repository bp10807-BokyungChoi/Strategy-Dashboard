# 전략팀 업무·상부 피드백 통합 관리 대시보드

전략 과제의 실행 담당·기한·마일스톤과 상부 의견의 전달·반영 상태를 연결하는 정적 웹 도구입니다. 전략팀의 방향 제시·조율·진척 점검과 실행부서의 구체적 실행안 기획 책임을 구분합니다.

## 시작

- `index.html`: 업무 대시보드·발표자료·검토 페이지 진입 화면
- `strategy-dashboard/index.html`: 과제·일정·상부 피드백·회의 및 보고
- `presentation.html`: 캡처 5장을 포함한 발표자료 7장 초안
- `review.html`: 검토 1차. 장별 코멘트 자동 저장 및 수정 요청 복사

GitHub Pages에서 열거나, 저장소 폴더에서 `python -m http.server 8000`을 실행한 뒤 `http://localhost:8000`에 접속합니다. 대시보드는 HTML을 직접 열어 사용할 수도 있습니다. 브라우저·주소가 바뀌면 저장 공간도 분리됩니다.

## 데이터와 현재 범위

업무 데이터는 브라우저 localStorage에 저장됩니다. 서버로 전송하거나 공동 편집하지 않습니다. 실제 업무 공간은 비어 있으며 가상 예시는 별도 모드로 제공합니다. 실제 업무 데이터를 소스 파일에 넣지 마세요. 기기 이동이나 브라우저 데이터 삭제 전 JSON 백업을 보관하세요.

과제 완료에는 완료 기준·근거·실제 완료일이, 상부 의견의 반영 확인에는 개별 완료 기준·반영 근거가 필요합니다. 합의 기한 변경에는 사유와 확정 주체를 기록합니다. 진행 상태와 일정 위험을 구분하며 과제 건수를 전략 성과로 표시하지 않습니다.

회의록 액션 자동 추출, 사내 시스템 연결, 서버 저장·권한·공동 사용은 후속 범위입니다. 발표자료와 검토 페이지는 현재 검토 중인 초안입니다. 검토 코멘트는 입력한 브라우저에만 저장되며 저장소나 다른 사람에게 자동 공유되지 않습니다.

## 파일 구성

- `strategy-dashboard/`: HTML·CSS·JavaScript·업무 로직 테스트·구현 기록
- `.agents/skills/strategy-team-operations/`: 재사용 가능한 전략팀 업무 관리 스킬
- `screenshots/`: 사용자 확인을 받은 가상 예시 캡처 원본 5장
- 한글 과제명 `.html`: 이미지를 포함한 단일 발표 파일
- `_작업본.html`: 이미지 삽입 전 편집용 파일
- `_검토.html`: 장별 검토 페이지
- `최종과제템플릿.html`: 원본 발표 템플릿

다른 저장소의 Git 이력·공통 교육 데이터, 원본 녹음·전사, 개인 로컬 경로가 든 임시 스크립트, 음성 인식 모델·설치 환경은 포함하지 않습니다.

## 검증

`node --test strategy-dashboard/core.test.js`

일정 경계, 완료 조건, 전달·반영 구분, 백업·연결·이력, 보고 내용 등 핵심 업무 로직 테스트 10개를 제공합니다. 발표자료의 원본 템플릿 CSS와 내비게이션 스크립트는 유지했습니다.

## GitHub Pages

배포 소스는 `main` 브랜치의 루트(`/`)를 사용합니다. 저장소 권한·계정 요금제에 따라 비공개 저장소의 Pages 사용 가능 여부는 달라질 수 있습니다. 실제 배포 상태는 저장소 Settings의 Pages에서 확인합니다.
