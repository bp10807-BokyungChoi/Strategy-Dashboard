# 전략팀 운영 양식

필요한 양식만 선택하고 기존 관리 체계가 있으면 열과 명칭을 맞춘다. 아래 빈 표는 실제 과제를 의미하지 않는다. 값이 없으면 `확인 필요`, 적용 대상이 아니면 `해당 없음`, 제안 단계면 `제안/합의 필요`로 표시한다. 넓은 표는 산출물 형식에 따라 분리하되 ID로 연결한다.

## 협의체 안건·회의 결과

- 회의체 / 일시 / 참석 부서·담당 / 자료 기준일
- 지난 합의와 상부 피드백: 완료 근거, 미이행 항목과 영향
- 안건: 관련 ID, 공유·협의·결정 요청, 논점, 선택지, 결정 필요 시점
- 회의 결과: 합의한 사항, 확정 결정과 결정 주체, 이견·미결 쟁점
- 후속 조치: 실행 ID, 담당, 기한, 완료 기준
- 상부 보고 사항 / 다음 점검 일정

## 상부 보고 초안

1. **기준일·범위와 핵심 판단:** 현재 상황 및 전략 목표에 미치는 영향.
2. **주요 변화와 마일스톤:** 지난 보고 대비 변화, 합의 기한·예상일 차이, 완료 근거.
3. **위험과 대응:** 원인, 영향, 대응 담당과 일정, 부서 간 조율 필요 사항.
4. **결정 요청:** 관련 결정 ID, 선택지·영향, 권고·근거, 결정 주체와 필요일.
5. **상부 피드백 이행:** 전달·반영 현황, 확인 근거, 미해결 사항.
6. **다음 기간 계획:** 실행부서가 합의한 행동과 점검 시점. 제안은 구분해 표시.

요청에 해당하는 항목만 사용한다. 근거 없는 전체 진행률이나 낙관적 완료 전망을 추가하지 않는다.
